# Delivery brief

Use this format for the handoff to `team-delivery-workflow`.

```text
Issue: <link/number>
Outcome: <user-visible result>
Type and priority: <bug | feature | other>; <P0/P1/P2/P3>
Evidence: <links, logs, screenshots, reproduction, or “none supplied”>
Impact and affected area: <who/what is affected>
Acceptance criteria:
- <observable condition>
Out of scope:
- <excluded behavior>
Constraints: <compatibility, timing, deployment, or “none known”>
Open questions: <material decisions only, or “none”>
Intake conclusion: <ready for delivery | blocked>
```
